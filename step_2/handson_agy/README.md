# ⚡ NEON BREAKOUT (ネオン・ブロック崩し)

Flutter Web, iOS, Android のマルチプラットフォームに対応した、ネオンサイバースタイルの爽快ブロック崩しゲームです。

---

## 🎮 主な機能 & 特徴

### 1. マルチプラットフォーム完全対応
- **Web (PC/ブラウザ)**:
  - キーボード操作: `[←]` / `[→]` または `[A]` / `[D]` でパドル移動
  - スペースキー: ボール発射 / 一時停止（ポーズ）
  - マウス操作: カーソル追従による滑らかなパドル移動
  - ワイド画面時にアーケード筐体風の **SYSTEM HUD & 操作ガイドサイドバー** を表示
- **Mobile (iOS / Android)**:
  - 直感的なタッチドラッグ操作
  - 片手プレイに便利な **オンスクリーン左右ボタン & LAUNCHボタン**（画面右上のアイコンでON/OFF切替可能）
  - 爽快な触覚フィードバック（HapticFeedback）

### 2. 多彩なブロック & ギミック
- **通常ブロック (Normal)**: カラフルなネオンカラー、1ヒットで破壊
- **強化ブロック (Hard / Iron)**: 耐久値2〜3ヒット。ダメージでひび割れエフェクト
- **爆弾ブロック (Bomb)**: 破壊すると周囲8方向のブロックを巻き込んでド派手に誘爆
- **アイテムブロック (Power-up)**: 破壊するとパワーアップカプセルをドロップ

### 3. パワーアップカプセル (6種類)
- 🔵 **MULTI BALL (M)**: ボールが分裂して3つのマルチボールに！
- 🟢 **WIDE PADDLE (W)**: パドルの幅が1.5倍に拡大！
- 🔥 **FIRE BALL (F)**: ブロックを跳ね返らずに一気に貫通！
- 🛡️ **LASER SHIELD (L)**: 画面最下部にセーフティバリアを展開し、ボール落下を1回防ぐ！
- ⚡ **SLOW MOTION (S)**: ボール速度を一時的に落ち着かせ、ピンチを回避！
- ❤️ **EXTRA LIFE (+)**: 残機（ライフ）+1！

### 4. 充実の全5ステージ構成
- **Stage 1**: CYBER DAWN（基本配置）
- **Stage 2**: NEON PYRAMID（ピラミッド型配置）
- **Stage 3**: FORTRESS（頑丈ブロックと爆弾ブロックの要塞）
- **Stage 4**: ALIEN MATRIX（スペースインベーダーフォーメーション）
- **Stage 5**: QUANTUM CORE（コアブロックを守る最終決戦）

## 🚀 起動方法

### Web版で実行:
```bash
flutter run -d chrome
```

### iOSシミュレータ / 実機で実行:
```bash
flutter run -d ios
```

### Androidエミュレータ / 実機で実行:
```bash
flutter run -d android
```

### テスト実行:
```bash
flutter test
```

### Webプロダクションビルド:
```bash
flutter build web
```
ビルド成果物は `build/web/` に生成されます。
